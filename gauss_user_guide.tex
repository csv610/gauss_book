\section{Introduction}

This guide accompanies the book \textit{Exploring Gauss's Mathematics using Python}. It provides step-by-step instructions for running the code, understanding the mathematical concepts, and extending the implementations.

\subsection{Prerequisites}

\begin{itemize}
    \item Python 3.8+
    \item Required packages: \texttt{numpy}, \texttt{scipy}, \texttt{matplotlib}, \texttt{pytest}
    \item Basic familiarity with Python and Jupyter notebooks
    \item Mathematical background: calculus, linear algebra, basic number theory
\end{itemize}

\section{Troubleshooting}

\subsection{Common Issues}

\begin{enumerate}
    \item \textbf{Module not found}: Ensure you're in the project root and PYTHONPATH includes the project directory.
    \item \textbf{Numerical precision}: Some algorithms (especially AGM) converge very fast; adjust tolerance as needed.
    \item \textbf{Slow tests}: Run \texttt{pytest tests/ -x} to stop on first failure.
\end{enumerate}

\subsection{Performance Tips}
\begin{itemize}
    \item Use \texttt{numpy} vectorized operations instead of loops
    \item For AGM, the quadratic convergence means 5-6 iterations give full double precision
    \item Gaussian elimination: prefer QR or Cholesky for stability
\end{itemize}

\section{Frequently Asked Questions}
\begin{description}
  \item[Q: I get a "ModuleNotFoundError" when trying to run a module. What should I do?]
  \item[A:] Ensure you are running the command from the project's root directory (the folder containing the {\tt python/} and {\tt tests/} directories). If you are using an IDE, set the working directory accordingly, or add the project root to your {\tt PYTHONPATH} environment variable.
  \item[Q: Some tests are failing due to numerical precision. Is this normal?]
  \item[A:] Yes. Algorithms that rely on floating-point arithmetic (e.g., AGM, QR decomposition, Gaussian quadrature) may produce results that differ from the expected values by a small tolerance. The test suite uses relative/absolute tolerances (typically 1e-10 or 1e-12) to account for this. If a failure persists, increase the tolerance in the corresponding test or check that you are using the same version of NumPy/SciPy as specified in the requirements.
  \item[Q: How can I visualize the lemniscate or other special functions?]
  \item[A:] Many modules generate plots when executed as a script. For example, to plot the lemniscate sine and cosine:
  \begin{verbatim}
  import numpy as np
  import matplotlib.pyplot as plt
  from python.lemniscate import sl, cl
  t = np.linspace(0, 4, 400)
  plt.plot(t, [sl(x) for x in t], label='sl(t)')
  plt.plot(t, [cl(x) for x in t], label='cl(t)')
  plt.legend()
  plt.grid(True)
  plt.show()
  \end{verbatim}
  Similar snippets are provided in the "Visualizing Results" section of this guide.
  \item[Q: I want to experiment with a new quadrature rule (e.g., Gauss-Jacobi). Where should I add it?]
  \item[A:] Add your implementation to {\tt python/gauss\_quadrature.py} following the pattern of the existing {\tt gauss\_legendre}, {\tt gauss\_hermite}, etc. functions. Then expose it in the module's {\tt \_\_all\_\_} list if desired, and write a short demo in the "Visualizing Results" section or a new subsection under "Extending the Code".
  \item[Q: The Gaussian Process examples seem slow. How can I speed them up?]
  \item[A:] For small datasets the pure-Python implementation is fine. For larger data:
  \begin{itemize}
    \item Use the {\tt scipy.optimize.minimize} wrapper in {\tt GaussianProcess.optimize\_hyperparameters} instead of a simple grid search.
    \item Pre-compute the kernel matrix and use Cholesky factorization for repeated predictions.
    \item Consider switching to a specialized GP library (e.g., GPy, GPflow) for production-scale applications.
  \end{itemize}
  \item[Q: Where can I find the mathematical derivations behind the algorithms?]
  \item[A:] The main book ({\tt gauss\_book.tex}) contains detailed derivations, historical notes, and proofs. For each algorithm, look for the corresponding "Theorem" or "Algorithm" environment in the relevant chapter. The user guide focuses on how to run and experiment with the code.
\end{description}
